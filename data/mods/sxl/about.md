SXL is an early alpha SD-card mod for the Akai MPC Sample by [Jsen Surreal](https://www.youtube.com/@jsensurreal1026). It runs from `autorun` on the card (extract the release to the card root). The maker describes it as rough alpha software: it can crash and restart to stock without flashing the device.

The alpha build adds multi-track sequencing (up to 32 tracks), sequence launching, a Sample Library, NAM amp modelling, CLAP plugins, USB host mode with class-compliant USB audio, a live looper, and pad strum / arp helpers. Included sound content (.sfz instruments and a Hype library) makes the download large; a fast microSD card is recommended.

It is stated to run on firmware **1.3** or **1.4** (listing notes: **1.3.0.12** or **1.4.0.7**; Developer Mode autorun is needed on 1.4). There is no public source repository yet. Downloads and the user manual are linked from the [alpha release video](https://www.youtube.com/watch?v=qmQVvTvBr2c) description (Google Drive).
