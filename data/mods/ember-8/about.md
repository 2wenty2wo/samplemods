## Instrument and sound

EMBER-8 adds a hybrid synthesizer to the MPC Sample's normal sampling and
beat-making workflow. The synth and the original MPC beat can play together.

- Each voice can combine three sources, A, B and C. Slots offer Analog, FM,
  Wavetable or Granular synthesis, or can be switched off. Eight voices are
  shared across the instrument. The images show an Ember Stack preset in the
  HYBRID editor.
- Wavetable and Granular sources can use samples assigned to pads in a saved
  MPC project. The sample picker auditions the selected source; save pad
  changes before importing them.

## Sequence and export

The LIVE sequencer records melodies from pads or a MIDI keyboard, with count-in
and overdubbing. Patterns support up to 64 steps; STEP EDIT provides an
alternative to live recording.

SAVE WAV exports a complete synth loop and its effects as stereo 44.1 kHz PCM16
audio. Wait for WAV READY, return to the MPC view with B3, then load the file
from `EMBER-8/Exports` onto a free pad through the normal sample browser. Export
does not assign it automatically.

## Stock MPC integration

Loading restarts the MPC application once to attach the synth; it is not a
firmware installation. Hold PAD FX while pressing KNOB FX to show or hide the
synth. B3 returns to the normal MPC view without unloading it.

## Requirements

- Firmware **1.3.0.12** (displayed as **1.3.0** on the device) for the main
  Workflow Beta package, or the separate **FW 1.4.x** package for 1.4 builds.
- An **exFAT microSD card** with the download's `autorun` folder, copied according
  to the maker's installation instructions.
- Saved projects and a backup before installing or updating.

## Beta and availability

The product page lists **0.15.2 Workflow Beta** plus an **FW 1.4.x** download; the
linked guide covers v0.9. The page was posted on 6 November and updated on
26 November 2026.

This is a development beta. Tempo and transport do not automatically follow
the MPC clock, so manually started playback can drift. The supplied images are
software-rendered interface previews.
