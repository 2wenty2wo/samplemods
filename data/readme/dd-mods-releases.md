# DD Mods — downloads

The public download home for DD Mods, a desktop companion and removable modifications for MPC Sample.

**Public beta downloads are not available yet.** Signing, compatibility and beta acceptance are being completed. No installer in this repository is currently approved for general use.

When releases are ready, use the **Releases** section for versioned Windows installers, signatures, checksums and release notes. Supported firmware builds and known limitations will be listed with each release.

Application updates and MPC mod-bundle updates are separate. Updating the MPC requires access to its SD card; an SD card alone does not establish the device's firmware version.

Source development is maintained separately. Manufacturer firmware, device credentials and user backups are not distributed here.
