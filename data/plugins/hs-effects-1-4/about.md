## What it is

Twenty-two Henry Skillz insert effects for a **stock** MPC Sample on firmware
1.4. No custom OS and no boot card: copy one folder onto the SD card and the
effects appear in an insert slot (HS-Pump, HS-Heat, HS-Para EQ and so on), each
with its own faceplate.

## Install

1. Download
   [HS-Effects-for-MPC-Sample-1.4.zip](https://www.henryskillz.com/downloads/HS-Effects-for-MPC-Sample-1.4.zip)
   from the [build log](https://www.henryskillz.com/mpc-sample).
2. Unzip and copy the `VST2 Plugins` folder to the top level of the SD card
   (merge if one already exists; do not rename folders inside it).
3. On the Sample, if Preferences shows Enhancements (Beta), turn on external
   plugin support.
4. Open an insert slot and choose an effect under Henry Skillz.

## Status

Emulator-tested on MPC XL firmware 3.10.1 and the plugin SDK test host. The
maker has not yet confirmed the pack on a real MPC Sample running 1.4 — treat
it as a test pack and back up the card first.
