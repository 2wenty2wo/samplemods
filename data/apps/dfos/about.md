DFOS (Damon Flores OS) is a free, independent custom OS for the Akai MPC Sample. It starts from an `autorun` folder on an exFAT microSD card, loads into memory with the stock sampler stopped, and returns to the stock app when you leave (power button → B2 · Stock OS).

The public beta ships sixteen tracks (drums, audio, MIDI, keygroup or plugin), a step Grid, song/arrange tools, a mixer with inserts and returns, sixteen USB audio outs, and two on-device stem splitters (Spleeter and HT-Demucs). Seven instruments are included: Strings, Keys, Poly, Organ, FM, Drums and Spark.

It is built for firmware **1.3.0.12** only; other firmware versions refuse to start and log the reason in `autorun/dfos-start.log`. There is no public GitHub repository — downloads are sent from [getdfos.com](https://getdfos.com/).

Sources: [Install](https://getdfos.com/install/), [Release notes](https://getdfos.com/release-notes/), [Changelog](https://getdfos.com/changelog/).
