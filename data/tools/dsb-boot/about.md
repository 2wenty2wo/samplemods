# HenrySkillz D.S.B Boot

A free SD-card boot menu for the MPC Sample. Before anything starts, a menu on the Sample's screen lets you run Stock, HS FX (stock with three HS effects: Para EQ, Tube Strip and Saturator), or any other OS built for the Sample from one card.

Turn the data encoder to browse, push to boot. Left alone, it starts the last system you used after a five-second countdown. SHIFT + turn switches between the Records and SD card themes. If a system crashes twice in a row, the next power-on defaults to Stock.

Install by putting the `autorun` folder from `dsb-boot-card.zip` straight on the SD card. Drop other OS folders into `autorun/os/` to add them to the menu.

Full walkthrough: [D.S.B guide — Boot](https://www.henryskillz.com/dsb-guide#boot).
