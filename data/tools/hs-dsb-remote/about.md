## What it is

HS-DSB Remote is Henry Skillz’s free TestFlight beta for iPhone, iPad and Mac.
It mirrors a supported USB-connected MPC Sample and lets you play pads, use
panel controls and shortcuts, customise a Map control grid, and optionally
monitor a selected USB audio input.

## Requirements

- A USB **data** cable (or compatible Lightning USB data adapter).
- Matching remote runtime on the SD card for full controls and Screen Mirror
  when using D.S.B or HS 25 setups. Stock firmware can use the Remote test
  card described on the maker’s build log.
- Compatibility notes and setup: [henryskillz.com/mpc-sample](https://www.henryskillz.com/mpc-sample).
