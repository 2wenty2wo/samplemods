# Security policy

This policy covers the Sample Mods website and build, GitHub Actions workflows, and data scripts in this repository. The site is a static SvelteKit catalog on GitHub Pages. It has no user accounts and stores no user data.

Report vulnerabilities in third-party mods or firmware to their authors. To ask Sample Mods to flag or remove a listing, use [Fix or update a listing](https://github.com/2wenty2wo/samplemods/issues/new?template=change-entry.yml).

Use GitHub's private vulnerability reporting. Open the repository's [Security tab](https://github.com/2wenty2wo/samplemods/security) and select **Report a vulnerability**. The maintainer reviews reports on a best-effort basis.
